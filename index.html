Connect to Google Sheets

This app stores all deals in a shared Google Sheet so your whole team stays in sync. Follow these steps once:

1
Create a new Google Sheet at sheets.new — name it anything (e.g. "Sales Funnel")
2
In the sheet, click Extensions → Apps Script. Delete any existing code, paste the entire contents of Code.gs and click Save
3
In Apps Script, click Run → Run function → setupSheets (grant permissions when asked)
4
Click Deploy → New deployment. Type: Web app. Execute as: Me. Access: Anyone. Deploy and copy the Web app URL
5
Paste the URL below and click Connect
